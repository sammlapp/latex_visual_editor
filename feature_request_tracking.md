# Feature requests

Citation autocomplete: after typing \citep{ \citet{ , the document bibliography entries are provided as an autocomplete-filtered list. Filters match on author names, citation keys, and title words, with full-word matching rather than split-up characters. For instance "lapp opensoundscape" should match on a bib item for Lapp, ....,2023 "Opensoundscape: an open-source...". Display up to 5-10ish matching items in a pop-up window, or perhaps a side panel. Latex Workshop has a feature like this that works well.

Table editing: tables are edited in a tabular layout, similar to google sheets, and content can be pasted from excel/google sheets. Basic formatting like inserting horizontal line-rules and merging/unmerging cells is supported. Columns resizing with text wrapping. Table-level controls for size/spacing of elelements. Might be best to use longtable automatically, or something that will allow tables that need to split across multiple pages.

Auto-complete of latex commands or symbols. For instance, when typing \bet should se "beta" as an auto-complete option. #

\include should render the input content as read-only, with a click to open source document link/button
